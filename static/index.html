Chào mừng đến với Zalo Gateway

Hệ thống cổng trung gian duy trì kết nối Zalo cá nhân 24/7. Bạn có thể mở link này trên nhiều máy tính cùng lúc hoặc dùng API/Webhook cho các công cụ tự động hóa (n8n, Make, AI Agent).

🪝 Quản lý Webhooks (Tự động hóa)

Đăng ký URL để tự động nhận tin nhắn Zalo gửi sang n8n, Make, Telegram Bot hoặc ứng dụng riêng của bạn.

Danh sách Webhook đang kích hoạt

📖 Tài liệu Kỹ thuật & API cho Tự động hóa / AI Agent

1. Gửi tin nhắn qua REST API

curl -X POST http://localhost:54321/api/v1/send \
  -H "Content-Type: application/json" \
  -d '{
    "thread_id": "1842365959181420185",
    "message": "Xin chào! Đây là tin nhắn tự động từ Zalo Gateway.",
    "is_group": false
  }'

2. Lấy danh sách tin nhắn

curl http://localhost:54321/api/v1/messages?limit=20

3. Kiểm tra trạng thái Gateway

curl http://localhost:54321/api/v1/status

Tích hợp n8n Workflow

  1. Tạo một node Webhook (HTTP Method: POST) trong n8n.
  2. Copy Test/Production Webhook URL từ n8n.
  3. Vào tab Quản lý Webhooks trên Zalo Gateway và dán URL vào.
  4. Mỗi khi có tin nhắn Zalo gửi đến, n8n sẽ nhận ngay payload JSON chứa: 
    {
  "event": "message.received",
  "timestamp": 1793718000000,
  "data": {
    "id": "8448...",
    "threadId": "1842365959181420185",
    "senderName": "Nguyễn Văn A",
    "content": "Chào bạn, cho mình hỏi giá sản phẩm...",
    "isGroup": false
  }
}

Dành cho AI Agent / LLMs

Tài liệu chuẩn hóa cho Agent được tự động phục vụ tại:

  • /agent-guide.md - Hướng dẫn chi tiết bằng Markdown cho Agent.
  • /llms.txt - File ngữ cảnh chuẩn AI LLMs.
  • /api/v1/openapi.json - Đặc tả OpenAPI 3.0 đầy đủ.

OpenAPI 3.0 Raw Specification

Bạn có thể import đường dẫn http://localhost:54321/api/v1/openapi.json vào Swagger Editor, Postman hoặc Custom GPT Actions.
